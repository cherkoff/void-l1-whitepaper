# Void-L1

Void-L1 is an experimental Rust-native Layer-1 protocol based on Proof-of-Ephemera.

It combines:
- stateless-style validation
- proof-carrying transactions
- accumulator-based state commitments
- reversible state expiry
- client-side VDF anti-spam
- bonded archive market for expired state recovery
